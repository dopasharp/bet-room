# BET ROOM ✉️

3D 봉투 내기 게임의 첫 번째 브라우저 프로토타입.

- 3인칭 3D 방, 카메라 360도 회전
- PC WASD/방향키, 모바일 조이스틱
- 가구 조사, 봉투 1개와 꽝 3개, 꽝 5초 정지
- 게임 시작 전 내기 문구 입력

**주의:** 현재는 로컬 1인 체험판입니다. Firebase Realtime Database 멀티플레이와 비밀 봉투 판정은 아직 구현되지 않았습니다.

예정: Firebase 방 생성/입장, 상대 캐릭터 위치 200ms 간격 동기화, 각자 비밀 배치, 상대 봉투를 먼저 열면 승리.
