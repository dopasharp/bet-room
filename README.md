# BET ROOM ✉️

3D 봉투 내기 게임의 브라우저 프로토타입.

- 3인칭 3D 집(토이 디오라마 스타일): 거실 + 주방 코너 + 방 + 화장실, 앞면은 열려 있음
- 카메라 360도 회전 · 카메라와 캐릭터 사이를 가리는 벽은 자동으로 투명해짐
- PC WASD/방향키, 모바일 조이스틱
- 조사 지점 16곳(방 4 · 주방 2 · 화장실 4 · 거실 6), 같은 방 안의 가구만 조사 가능
- 봉투 7개: 내기 1개 + 꽝 6개(❄️ 얼음 · 🌑 암흑 · 🔄 방향 반전 각 2개, 각 5초)
- 숨기기 도면은 세로 화면(휴대폰)에서 90도 돌려서 표시
- 내기는 각자 따로: "내가 이기면 상대가 할 일"을 숨기기 화면에서 판마다 적고, 이긴 사람의 내기가 적용됨(상대 내기는 상대가 숨기기를 끝내면 보임)
- 수색 타이머와 발견 기록(혼자 테스트는 최고 기록 저장)
- 🎲 랜덤 배치 버튼(누를 때마다 다시 섞음)
- 제스처: 👋 인사 · 😜 놀리기 · 🤔 뭐해?
- 효과음(WebAudio 합성, 파일 없음): 발소리, 가구별 여닫는 소리, 덜컹거림, 발견/허탕, 꽝 3종, 승리/패배, 카운트다운 · 🔊 버튼으로 끄기
- 긴장감: 시간이 갈수록 빨라지는 시계 소리

## 2인 대결 (Firebase Realtime Database)

- 방 만들기/코드 입장, 상대 캐릭터 위치 200ms 간격 동기화, 몸으로 밀기
- 둘 다 도면에 봉투를 숨기면 3-2-1 카운트다운 후 동시에 시작
- 각자 **상대가 숨긴** 봉투를 찾고, 먼저 내기 봉투를 연 사람이 승리
- 상대가 어디를 뒤지는지, 뭔가 발견했는지, 꽝에 걸렸는지 실시간 알림
- 상대가 여는 가구가 내 화면에서도 분홍빛으로 덜컹거리고 열림, 상대 발소리와 가구 소리는 거리·방향에 따라 들림
- 수색 중 내가 숨긴 봉투 위치가 머리 위 배지(✉️ 내 봉투 · ❄️🌑🔄 내 꽝)로 보임, 상대가 걸린 꽝은 흐려지고 위험하면 내 봉투 배지가 빨갛게 뜀
- 새로고침 후 같은 방 코드로 다시 입장하면 원래 자리(A/B)로 복귀
- 상대가 내 내기 봉투를 숨긴 곳 근처에 오면 심장 박동 소리와 붉은 화면 테두리, 그 자리를 뒤지면 경보

**플레이어 1 · 2:** 방을 만든 사람이 플레이어 1, 코드로 들어온 사람이 플레이어 2예요. 플레이어 2가 들어오면 플레이어 1의 초대 QR이 자동으로 닫히고 봉투 숨기기로 넘어가요. 같은 브라우저의 다른 탭으로 입장해도 자동으로 두 번째 익명 로그인을 써서 플레이어 2가 돼요.

**아이폰 무음 모드:** 첫 터치 때 미디어 재생으로 전환해서 무음 스위치가 켜져 있어도 소리가 나요(iOS 17+ `audioSession`, 그 이전은 무음 루프 오디오).

**주의:** 상대의 배치(`rooms/{code}/players/{seat}/loot`)는 DB에서 읽을 수 있어 개발자 도구로 엿볼 수 있습니다. 비밀 판정은 아직 서버에서 하지 않습니다.
